# Java Log Analyzer CLI

A lightweight command-line tool for quickly analyzing application log files — summarizing entries, isolating errors and warnings, and searching by keyword without opening a log viewer.

Built with Java — file I/O, collections, OOP, unit tested.

## Usage

```bash
logtool help
logtool summary <file>
logtool errors <file>
logtool warnings <file>
logtool search <keyword> <file>
```
