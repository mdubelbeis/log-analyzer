# Java Log Analyzer CLI

A command-line Java application for reading and analyzing application log files. This project is designed to strengthen core Java skills including file handling, command-line input, string processing, collections, error handling, and clean program structure.

## Features

- Read log files from the command line
- Display log summaries
- Count total log lines
- Filter `ERROR` and `WARN` entries
- Search log contents by keyword
- Provide clear usage and error messages

## Planned Commands

```bash
logtool help
logtool summary <file>
logtool errors <file>
logtool warnings <file>
logtool search <keyword> <file>
```

## Project Goals

The goal of this project is to build a practical Java CLI tool while improving software engineering fundamentals:

* Java CLI application structure
* Argument validation
* File input/output
* Log parsing
* Use of Lists, Maps, and Sets
* Object-oriented design
* Unit testing
* Professional Git workflow
